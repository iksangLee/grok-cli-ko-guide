# 04-슬래시 명령어

Grok Build에서는 프롬프트 입력란에서 `/` (슬래시)를 입력하면 다양한 **슬래시 명령어**를 빠르게 사용할 수 있습니다.

이 명령어들은 긴 문장을 입력하지 않고도, Grok에게 특정 동작을 빠르게 지시할 수 있게 해줍니다. 명령어를 입력하면 자동완성(Autocomplete)도 지원되기 때문에, 정확한 명령어를 몰라도 쉽게 사용할 수 있습니다.

슬래시 명령어는 크게 두 가지로 나뉩니다:

- **Shell builtins**: Grok의 백엔드에서 처리하는 명령어
- **Pager builtins**: TUI(프론트엔드)에서 처리하는 명령어

또한, 사용자가 만든 **Skills**도 슬래시 명령어로 등록되어 `/skill-name` 형태로 사용할 수 있습니다.

---

## 세션 관리 (Session Management)

### `/new`

현재 대화를 완전히 초기화하고 **새로운 세션**을 시작합니다.

```
 /new
```

- 별칭: `/clear`
- 이전 대화 내용은 모두 사라지며, 새로운 대화를 시작하고 싶을 때 사용합니다.
- 프로젝트를 바꾸거나, 완전히 다른 주제로 대화하고 싶을 때 유용합니다.

**실전 팁**: 긴 대화를 하다가 “이제 다른 얘기 해보자” 싶을 때 `/new`를 자주 사용합니다.

---

### `/load [session-id]`

이전에 저장된 세션을 불러옵니다.

```
 /load
 /load abc123def456
```

- `session-id`를 생략하면, 저장된 세션 목록을 보여주고 선택할 수 있습니다.
- 별칭: `/resume`
- 이전에 하던 대화를 이어서 하고 싶을 때 사용합니다.

**실전 팁**: 중요한 대화가 있었다면, 나중에 `/load`로 불러와서 이어서 진행할 수 있습니다.

---

### `/compact [context]`

현재 대화 기록을 **압축(요약)**하여 컨텍스트 창 공간을 확보합니다.

```
 /compact
 /compact keep the authentication logic
```

- 대화가 길어져서 토큰이 부족해질 때 사용합니다.
- 선택적으로 “이 부분은 꼭 유지해줘”라고 지정할 수 있습니다.
- Grok은 컨텍스트의 85%가 차면 자동으로 압축을 시도합니다 (설정에서 변경 가능).

**실전 팁**: 중요한 정보를 잃고 싶지 않을 때, `/compact keep ...` 문법을 활용하면 좋습니다.

---

### `/context`

현재 세션의 **컨텍스트 사용량**과 세션 정보를 보여줍니다.

```
 /context
```

- 현재 사용 중인 토큰 양, 남은 공간, 세션 ID 등을 확인할 수 있습니다.
- 대화가 길어질수록 이 명령어를 자주 사용하게 됩니다.

---

### `/session-info`

현재 세션의 상세 정보를 보여줍니다.

```
 /session-info
```

- 사용 중인 모델, 턴 수, 컨텍스트 사용량, 세션 생성 시간 등을 확인할 수 있습니다.
- `/context`보다 더 자세한 정보를 제공합니다.

---

## 모델 변경 관련 명령어

### `/model [model-name]`

현재 세션에서 사용할 모델을 변경합니다.

```
 /model grok-4
 /model
```

- 모델 이름을 지정하지 않으면 사용 가능한 모델 목록을 보여줍니다.
- 세션 중간에 모델을 바꾸고 싶을 때 유용합니다.

**실전 팁**: 가벼운 작업은 빠른 모델로, 복잡한 작업은 고성능 모델로 전환하면서 사용할 수 있습니다.

---

### `/models`

사용 가능한 모델 목록을 보여줍니다.

```
 /models
```

- 현재 사용 가능한 모델과 각각의 특징을 확인할 수 있습니다.
- Custom Models을 추가한 경우에도 여기서 확인됩니다.

---

## 플러그인 / MCP / 훅 관리 명령어

### `/plugins`

플러그인 관리 모달을 엽니다.

```
 /plugins
 /plugins list
 /plugins reload
 /plugins trust <path>
```

- `list`: 설치된 플러그인 목록 보기
- `reload`: 모든 플러그인 다시 로드
- `trust`: 신뢰할 수 없는 플러그인을 신뢰하도록 설정

**Ctrl + L** 단축키와 동일한 기능을 합니다.

---

### `/mcp`

MCP 서버 관리와 관련된 명령어를 제공합니다.

```
 /mcp list
 /mcp add <name> --command ...
 /mcp remove <name>
```

- MCP 서버를 CLI에서 직접 추가/제거/확인할 수 있습니다.
- TUI에서 `Ctrl + L` → MCP 탭과 유사한 기능을 제공합니다.

---

### `/hooks`

Hook 관리 모달을 엽니다.

```
 /hooks
 /hooks trust
```

- 현재 로드된 Hook 목록 확인
- 프로젝트 Hook 신뢰(trust) 설정

---

## 디버깅 및 정보 확인 명령어

### `/inspect`

현재 세션에서 로드된 Skills, MCP 서버, Plugins, Hooks 등의 상태를 확인합니다.

```
 /inspect
 /inspect --json
```

- 어떤 Skill이 로드되었는지, 어떤 MCP 서버가 연결되었는지 등을 한눈에 볼 수 있습니다.
- 문제 해결 시 매우 유용한 명령어입니다.

---

### `/help`

사용 가능한 슬래시 명령어 목록을 보여줍니다.

```
 /help
```

- 어떤 슬래시 명령어가 있는지 잊어버렸을 때 빠르게 확인할 수 있습니다.

---

### `/context` 와 `/session-info` (복습)

이미 1차 배치에서 다뤘지만, 다시 한 번 강조합니다.

- `/context`: 현재 컨텍스트 사용량 확인
- `/session-info`: 세션 상세 정보 (모델, 턴 수, 토큰 사용량 등)

긴 대화를 할수록 이 두 명령어를 자주 사용하게 됩니다.

---

## Skills를 슬래시 명령어로 사용하기

사용자가 만든 Skill은 자동으로 슬래시 명령어로 등록됩니다.

예를 들어, `commit-message`라는 이름의 Skill을 만들었다면:

```
 /commit-message
```

또는 더 짧게:

```
 /commit
```

**장점**:
- 긴 설명을 매번 입력하지 않아도 됨
- Skill의 `description`에 따라 Grok이 자동으로 언제 사용할지 판단함
- `/skills` 명령어로 등록된 Skill 목록 확인 가능

## 전체 슬래시 명령어 카테고리별 정리

아래는 현재 Grok Build에서 사용할 수 있는 주요 슬래시 명령어를 카테고리별로 정리한 것입니다.

### 세션 관리
- `/new` 또는 `/clear` — 새 세션 시작
- `/load [id]` 또는 `/resume` — 이전 세션 불러오기
- `/compact [keep ...]` — 대화 압축
- `/context` — 컨텍스트 사용량 확인
- `/session-info` — 세션 상세 정보

### 모델 관리
- `/model [name]` — 모델 변경
- `/models` — 사용 가능한 모델 목록

### 확장 기능 관리
- `/plugins` — 플러그인 관리 모달
- `/plugins list` — 설치된 플러그인 목록
- `/plugins reload` — 플러그인 새로고침
- `/plugins trust <path>` — 플러그인 신뢰 설정
- `/mcp` — MCP 서버 관리
- `/hooks` — Hook 관리
- `/hooks trust` — 프로젝트 Hook 신뢰 설정

### 디버깅 및 정보
- `/inspect` — 로드된 Skills, MCP, Plugins, Hooks 상태 확인
- `/inspect --json` — JSON 형식으로 상세 정보
- `/help` — 사용 가능한 슬래시 명령어 목록
- `/context` — 컨텍스트 상태 (중복 사용 가능)

### Skills
- `/skills` — 등록된 Skill 목록
- `/skills <name>` — 특정 Skill 주입
- `/<skill-name>` — Skill을 직접 호출 (예: `/commit`, `/review-pr`)

## 실전에서 가장 많이 쓰이는 명령어 조합 추천

### 1. 긴 대화 중 컨텍스트 관리
```
/context
/compact keep the authentication logic and project structure
```

### 2. 새로운 작업 시작
```
/new
/model grok-4
```

### 3. 팀 표준 적용
```
/plugins reload
/skills
```

### 4. 문제 해결
```
/inspect
/help
```

### 5. YOLO 모드 + 빠른 작업
```
Ctrl + O (YOLO on)
/new
... 작업 ...
Ctrl + O (YOLO off)
```

## 슬래시 명령어 관련 FAQ

**Q. 슬래시 명령어가 자동완성되지 않아요.**
- `/`를 입력한 후 잠시 기다려보세요. 자동완성이 나타납니다.
- Skill이 제대로 로드되지 않았을 수도 있습니다. `/skills`로 확인해보세요.

**Q. `/inspect`로 확인했는데 Skill이 안 보여요.**
- Skill 파일 위치와 `SKILL.md` 형식을 다시 확인하세요.
- `/skills reload` 또는 전체 재시작을 해보세요.

**Q. `/compact`를 해도 컨텍스트가 많이 줄지 않아요.**
- `keep` 옵션을 사용해서 중요한 부분은 유지하면서 압축할 수 있습니다.
- 너무 많은 정보를 keep 하면 압축 효과가 적습니다.

**Q. `/model`로 모델을 바꿨는데 이상해요.**
- 일부 모델은 특정 작업에 더 적합합니다. 웹 검색, 코드 생성, 긴 대화 등 용도에 따라 모델을 선택하는 것이 좋습니다.

**Q. `/plugins trust`는 언제 사용하나요?**
- 신뢰할 수 없는 플러그인(예: 외부에서 받은 Plugin)을 실행하려고 할 때 사용합니다. 보안상 중요한 명령어입니다.

여기까지 Grok Build에서 사용할 수 있는 주요 슬래시 명령어들을 정리했습니다.

슬래시 명령어는 **긴 문장을 입력하지 않고도** Grok에게 빠르게 지시할 수 있는 가장 편리한 방법 중 하나입니다.

특히 아래 명령어들은 거의 매일 사용하게 될 가능성이 높습니다:

- `/new`
- `/load`
- `/compact`
- `/context`
- `/inspect`
- `/plugins`
- `/model`

이 문서를 자주 참고하면서, 자주 쓰는 명령어 몇 가지만이라도 익혀두면 Grok Build 사용 경험이 훨씬 더 부드러워질 것입니다.

필요한 명령어가 더 있거나, 특정 명령어의 사용법을 더 자세히 알고 싶다면 언제든 말씀해주세요.
