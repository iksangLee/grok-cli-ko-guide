# 03-키보드 단축키

Grok Build는 터미널 전체 화면 TUI로 동작하기 때문에, **키보드 단축키**를 잘 아는 것이 생산성에 큰 영향을 미칩니다.

이 문서는 단순히 단축키 목록을 나열하는 것이 아니라, **처음 사용자도 이해하기 쉽게** 어떤 상황에서 어떤 키를 쓰면 좋은지 중심으로 정리했습니다.

---

## 입력 모드 (Input Modes)

Grok Build에는 두 가지 입력 모드가 있습니다.

### 1. Simple Mode (기본 모드)

- **기본으로 활성화**되어 있습니다.
- 화살표 키(↑ ↓ ← →)로 스크롤백을 이동할 수 있습니다.
- `Shift + 화살표`로 턴(사용자 메시지 단위) 이동이 가능합니다.
- 아무 글자나 누르면 자동으로 프롬프트 입력란에 포커스가 갑니다.

**추천 대상**: 대부분의 사용자, 특히 처음 시작하는 사람

### 2. Vim Mode (Vim 스타일 모드)

- `config.toml`에서 `simple_mode = false`로 설정하면 활성화됩니다.
- Vim 사용자에게 익숙한 `j` / `k` 키로 이동합니다.
- `h` / `l` 로 블록을 접고 펼칠 수 있습니다.
- 더 많은 단축키를 사용할 수 있지만, 처음에는 적응이 필요합니다.

**추천 대상**: Vim을 주로 사용하는 사람, 키보드 중심으로 빠르게 작업하고 싶은 사람

> **팁**: 처음에는 Simple Mode로 충분히 사용해보고, 나중에 Vim Mode로 전환하는 것을 추천합니다.

---

## 탐색 단축키 (Navigation)

스크롤백(위쪽 대화 영역)에 포커스가 있을 때 사용하는 이동 관련 단축키입니다.

| 기능                    | Vim Mode     | Simple Mode          | 설명 |
|-------------------------|--------------|----------------------|------|
| 다음 항목 선택          | `j`          | `↓`                  | 아래로 이동 |
| 이전 항목 선택          | `k`          | `↑`                  | 위로 이동 |
| 다음 턴으로 이동        | `Shift + L`  | `Shift + →`          | 다음 사용자 메시지로 점프 |
| 이전 턴으로 이동        | `Shift + H`  | `Shift + ←`          | 이전 사용자 메시지로 점프 |
| 맨 위로 이동            | `g`          | -                    | 스크롤백 최상단 |
| 맨 아래로 이동          | `Shift + G`  | -                    | 스크롤백 최하단 |
| 한 줄 위로 스크롤       | `Ctrl + K`   | -                    | 선택은 유지한 채 화면 이동 |
| 한 줄 아래로 스크롤     | `Ctrl + J`   | -                    | 선택은 유지한 채 화면 이동 |
| 한 페이지 위로          | `Page Up`    | `Page Up`            | 빠른 이동 |
| 한 페이지 아래로        | `Page Down`  | `Page Down`          | 빠른 이동 |
| 반 페이지 위로          | `Ctrl + U`   | -                    | 중간 속도 이동 |
| 반 페이지 아래로        | `Ctrl + D`   | -                    | 중간 속도 이동 |

**실전 팁**:
- `Shift + H` / `Shift + L` 은 대화가 길어졌을 때 **이전/다음 질문**으로 빠르게 이동할 때 매우 유용합니다.
- `g` 와 `Shift + G` 는 긴 대화에서 특정 부분을 찾을 때 자주 사용됩니다.

---

## 보기 제어 단축키 (View)

스크롤백에 표시되는 내용의 형태를 제어하는 단축키입니다.

| 기능                        | Vim Mode     | Simple Mode     | 설명 |
|-----------------------------|--------------|-----------------|------|
| 선택한 항목 접기            | `h`          | `←`             | 내용 숨기기 |
| 선택한 항목 펼치기          | `l`          | `→`             | 내용 보기 |
| 선택한 항목 접기/펼치기 토글 | `e`          | -               | 토글 |
| 모든 항목 접기/펼치기       | `Shift + E`  | -               | 전체 토글 |
| Thinking Block 전체 토글    | `Ctrl + Shift + E` | -         | 사고 과정 블록 전체 |
| Turn View 모드 전환         | `Shift + T`  | -               | 전체 턴 보기 ↔ 단일 턴 보기 |
| Raw Markdown 보기           | `r`          | -               | 원본 마크다운으로 보기 |

### 블록 내용 복사

| 기능                    | 단축키     | 설명 |
|-------------------------|------------|------|
| 내용 복사               | `y`        | 현재 선택된 블록 내용 복사 |
| 메타데이터 복사         | `Shift + Y`| 명령어, 파일 경로 등 메타데이터 복사 |

**실전 팁**:
- `y` 키는 Grok이 실행한 shell 명령어나 생성된 코드를 빠르게 복사할 때 매우 유용합니다.
- `Shift + Y` 는 “이 명령어가 정확히 뭐였더라?” 싶을 때 메타데이터를 확인할 수 있습니다.

## Prompt 입력란 단축키

프롬프트 입력란(하단 입력창)에 포커스가 있을 때 유용한 단축키입니다.

| 기능                    | 단축키          | 설명 |
|-------------------------|-----------------|------|
| 입력란 포커스 이동      | `Space`, `i`, `Tab` | 스크롤백 ↔ 프롬프트 전환 |
| 이전 입력 기록 불러오기 | `↑`             | 최근에 입력한 메시지 불러오기 |
| 다음 입력 기록 불러오기 | `↓`             | 다음 입력 기록으로 이동 |
| 입력 취소               | `Ctrl + C`      | 현재 입력 취소 |
| 줄바꿈 (멀티라인)       | `Shift + Enter` | 긴 프롬프트 작성 시 사용 |
| 전체 입력 지우기        | `Ctrl + U`      | 입력한 내용 모두 삭제 |

**실전 팁**:
- `Space` 키는 스크롤백을 보고 있다가 바로 입력하고 싶을 때 가장 빠른 방법입니다.
- 긴 작업을 요청할 때는 `Shift + Enter`로 줄을 나눠서 작성하면 가독성이 좋습니다.

---

## 전역(Global) 단축키

스크롤백과 프롬프트 어디에서든 사용할 수 있는 중요한 단축키들입니다.

| 기능                    | 단축키          | 설명 |
|-------------------------|-----------------|------|
| 새 세션 시작            | `Ctrl + N`      | 완전히 새로운 대화 시작 |
| YOLO 모드 토글          | `Ctrl + O`      | 자동 승인 모드 on/off |
| 플러그인 관리 열기      | `Ctrl + L`      | Plugins, Marketplace, Hooks, MCP 관리 |
| 도움말 / 명령어 보기    | `Ctrl + ?` 또는 `?` | 사용 가능한 명령어 확인 |
| 세션 목록 보기          | `/load`         | 이전 세션 불러오기 |
| 현재 세션 압축          | `/compact`      | 대화 기록 압축 (토큰 절약) |
| 모델 변경               | `/model`        | 사용할 모델 변경 |

**특히 중요한 단축키**

- `Ctrl + N`: 새 프로젝트나 완전히 다른 주제를 시작할 때 자주 사용
- `Ctrl + O`: YOLO 모드를 빠르게 켜고 끄는 데 매우 유용
- `Ctrl + L`: Plugins, MCP, Hooks, Marketplace를 관리할 때 가장 많이 쓰는 단축키

## Thinking Block 전용 단축키

Grok이 생각하는 과정(Thinking Block)을 다루는 단축키입니다.

| 기능                        | 단축키             | 설명 |
|-----------------------------|--------------------|------|
| Thinking Block 접기/펼치기  | `h` / `l`          | 선택된 Thinking Block 토글 |
| 모든 Thinking Block 토글    | `Ctrl + Shift + E` | 전체 사고 과정 한 번에 접거나 펼치기 |
| Thinking Block 내용 복사    | `y` (선택 후)      | 내부 사고 과정 내용 복사 |

**실전 팁**:
- 긴 대화에서는 `Ctrl + Shift + E`로 모든 Thinking Block을 접어두면 스크롤백이 훨씬 깔끔해집니다.
- 특정 Thinking Block만 자세히 보고 싶을 때는 `l` 키로 펼쳐서 확인하세요.

## 실전에서 가장 많이 쓰이는 단축키 Top 10

처음 사용자라면 아래 단축키부터 익히는 것을 추천합니다.

| 순위 | 단축키              | 용도 |
|------|---------------------|------|
| 1    | `Space`             | 빠르게 입력란으로 이동 |
| 2    | `j` / `k` 또는 `↑`/`↓` | 스크롤백 이동 |
| 3    | `h` / `l`           | 블록 접고 펼치기 |
| 4    | `y`                 | 내용 빠르게 복사 |
| 5    | `Ctrl + N`          | 새 세션 시작 |
| 6    | `Shift + H` / `Shift + L` | 이전/다음 턴 이동 |
| 7    | `Ctrl + O`          | YOLO 모드 토글 |
| 8    | `Ctrl + L`          | 플러그인/MCP 관리 |
| 9    | `g` / `Shift + G`   | 스크롤백 맨 위/아래 이동 |
| 10   | `e`                 | 선택한 항목 접기/펼치기 토글 |

### 추천 조합

- **긴 대화 탐색**: `Shift + H/L` + `j/k`
- **빠른 복사 후 질문**: `y` → `Space` → 질문 입력
- **YOLO로 빠르게 작업**: `Ctrl + O` → 작업 → `Ctrl + O` (다시 끄기)

## Vim Mode 사용자에게 유용한 고급 단축키

Vim Mode를 사용하는 사람들을 위한 추가 팁:

- `e` : 선택한 항목 fold 토글 (접고 펼치기)
- `Shift + E` : 전체 fold 토글 (모두 접거나 모두 펼치기)
- `r` : 선택한 블록을 Raw Markdown으로 보기 (디버깅이나 복사할 때 유용)
- `Shift + T` : All-turns view ↔ Single-turn view 전환 (긴 대화에서 유용)
- `Ctrl + Shift + E` : 모든 Thinking Block을 한 번에 접거나 펼치기

Vim Mode는 처음엔 어색할 수 있지만, 익숙해지면 **훨씬 빠르게** 대화를 탐색할 수 있습니다.

## 자주 묻는 질문 (FAQ)

**Q. 단축키가 안 먹혀요.**
- 스크롤백에 포커스가 있는지 확인하세요. (프롬프트에 포커스가 있으면 일부 단축키가 동작하지 않습니다.)
- `Space`를 눌러 스크롤백으로 포커스를 이동해보세요.

**Q. Vim Mode가 이상해요.**
- `simple_mode = false`로 설정했는지 확인하세요 (`~/.grok/config.toml`).
- Vim Mode는 `j/k/h/l` 중심으로 동작합니다. 화살표 키는 Simple Mode에서만 자연스럽게 작동합니다.

**Q. Thinking Block이 너무 많아서 정신없어요.**
- `Ctrl + Shift + E`로 모든 Thinking Block을 접어두세요.
- 필요할 때만 `l` 키로 펼쳐서 확인하는 걸 추천합니다.

**Q. 가장 추천하는 단축키 조합은?**
- `Shift + H/L` (턴 이동) + `j/k` (세밀 이동) + `y` (복사) + `Space` (입력) 조합이 가장 많이 쓰입니다.

**03-키보드-단축키.md 끝**

여기까지 Grok Build TUI에서 사용할 수 있는 주요 키보드 단축키를 정리했습니다.

**Simple Mode**로 충분히 시작하고, 익숙해지면 **Vim Mode**로 전환하는 걸 추천합니다.

자주 쓰는 단축키 몇 개만이라도 익혀두면, Grok Build 사용 경험이 확실히 빨라지고 편해집니다.

이 문서에서 다루지 않은 특수한 단축키가 필요하거나, Vim Mode에서 더 깊게 알고 싶다면 언제든 말씀해주세요.
